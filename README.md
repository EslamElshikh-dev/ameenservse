# أمين سرور لخدمات السباكة وصيانة الكهرباء

موقع عربي متجاوب لنشاط منزلي يعمل بنظام نطاق الخدمة داخل مدينة الرياض.

الموقع المنشور: [https://ameenservse.vercel.app/](https://ameenservse.vercel.app/)

## المحتوى

- 12 خدمة للسباكة وصيانة الكهرباء بأسماء وأوصاف مهيأة للبحث المحلي.
- أيقونات SVG داخلية وخفيفة بدل صور الخدمات الخارجية.
- أزرار اتصال وواتساب عائمة وروابط طلب مخصصة لكل خدمة.
- خريطة نطاق الخدمة والأسئلة الشائعة وبيانات منظمة لمحركات البحث.
- دعم اتجاه RTL، لوحة المفاتيح، وتقليل الحركة حسب إعداد الجهاز.

## التشغيل

الموقع ثابت ولا يحتاج إلى عملية بناء. افتح `index.html` مباشرة أو شغّله عبر أي خادم ملفات ثابتة.
